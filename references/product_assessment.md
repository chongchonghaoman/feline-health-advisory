# 猫食品商品审查流程

当用户给出猫粮、主食餐盒、主食罐、主食猫条、餐包、冻干、零食、营养补充品或多个商品，让你判断“能不能买、适不适合我的猫、健不健康、合不合规、安不安全”时，读本文件。

如果用户明确要求“找到配料表、准确配料信息、原料组成、成分分析保证值、背标、包装背面”，先读并执行 `ingredient_acquisition.md`。配料获取是独立硬流程，不要只用本文件给临时判断。

本流程不替代兽医营养处方。慢病、长期厌食、减重、肾病、糖尿病、胰腺炎、食物过敏、反复呕吐腹泻或幼猫发育异常，先回到分诊和兽医评估。

## 先提取的信息

优先从用户消息中提取；缺失时只追问会改变结论的 3-6 项。

- 猫：年龄、体重、性别/绝育、品种或体型、是否幼猫/老年、疫苗驱虫、慢病、近期呕吐腹泻、软便、拒食、体重变化。
- 商品：品牌、完整商品名、规格、口味、价格、购买渠道、是否旗舰店、国产/进口、试吃还是长期主食。
- 身份：平台商品 ID、SKU/规格选项、GTIN/EAN/UPC/商品条码、条码单位、包装版本、目标市场。
- 标签：正面品名、配料/原料组成、添加剂组成、产品成分分析保证值、适用生命阶段、产品标准号、生产/委托/进口信息、批号日期。
- 公开信息：品牌官网/旗舰店详情页、监管通报、召回、平台评价、近期集中投诉。

缺少配料表和保证分析时，不要给“品质很好/完全合规/放心囤”的结论；最多给基于已核信息的临时建议。

## 审查顺序

1. **急症和不良反应先行**  
   如果猫已出现反复呕吐、水样腹泻、便血、精神差、拒食、脱水、抽搐、疑似异物或多猫同批食物后发病，先按 `triage_red_flags.md` 分诊。不要继续做购物分析。

2. **确认商品身份**  
   用商品名、规格、口味、官方店铺、详情页图片、价格和平台 ID 交叉确认。多个相似 SKU 时，明确“我核到的是哪一款”；无法确认时标为“未完全匹配”，不要把别的口味或规格的配方套上去。
   电商标题只能作为搜索线索，不能作为标签事实。标题里的“幼猫/成猫通用、全价、主食、无谷、零添加、利尿、排毛、某品牌出品”等词，必须被背标、规格选择截图或官方详情图二次确认。

3. **判定食品类别与生命阶段**  
   区分全价主食、补充性湿粮/零食、主食猫条、普通猫条、营养膏/补充剂。给幼猫长期吃的主食必须满足“全价/完整均衡”且适合幼猫或全生命阶段；只标“成猫”“零食”“补充饲料/其他宠物饲料”的产品，不建议作为幼猫长期主食。

4. **合规标签检查**  
   面向中国商品时，优先检查是否有清晰品名、净含量、原料组成、添加剂组成、产品成分分析保证值、适用阶段、产品标准号、生产企业/委托生产信息、保质期、贮存条件、批号/日期、进口登记或中文标签。  
   不要因为“旗舰店”就默认合规；旗舰店只能降低渠道风险，不能替代标签审查。

5. **营养与健康适配**  
   先用 WSAVA 营养评估原则看生命阶段、体况、体重趋势、饮食史和慢病风险；再看该商品是否能承担用户想让它承担的角色。

   - 幼猫：优先完整均衡、适合生命阶段、稳定进食、便便稳定、体重增长。新口味先 5-10g 试吃；40g 对 2-3 月龄幼猫通常更像一小餐，不算“极少量试吃”。
   - 湿粮/餐盒/餐包：即使比干粮更容易接受，也要看是否全价、保证分析和开封保存；不要把“爱吃”当作健康证明。
   - 猫条：除非标签明确全价且有完整保证分析，否则默认按零食或诱食辅助处理，不当长期主食。
   - 鱼类口味：可轮换或试吃，但不建议让幼猫长期只吃鱼口味，避免口味固化和配方单一。

6. **安全与风评**  
   分开看官方召回/监管通报、批次问题、平台差评、社媒口碑和个体软便。

   - 官方召回、监管抽检、批次污染或大面积同症状投诉，权重大于零散好评。
   - 平台好评数量只能说明销量和满意度，不能证明配方安全。
   - “很多猫爱吃”不等于适合作主食；“有软便差评”也不等于所有猫不能吃，要看是否集中在同批次、同口味、同症状。

7. **价格只放最后**  
   价格用于判断是否“值得买/值得囤”，不是安全性的核心证据。先给健康、合规、安全结论，再说价格处在历史低位、近期好价、普通价还是信息不足。

## 证据分层

- `已核`：有官方页面、包装图、监管/标准平台或可核验详情页支持。
- `未核`：公开网页没有完整配料/保证分析/批号，或 SKU 没完全匹配。
- `存疑`：价格异常低、标签缺关键项、品类和用户用途不匹配、品牌/代工信息混乱、近期集中差评。
- `A/B/C/D 配料证据等级`：仅在用户要求准确配料时使用，详见 `ingredient_acquisition.md`。

## 输出格式

默认简洁。多个商品可用表格。每个商品至少给四项：

- **结论**：可买 / 可少量试 / 暂不建议 / 不建议当主食 / 信息不足先别囤。
- **适合谁**：是否适合当前这只猫的年龄、体况、主食或零食用途。
- **已核依据**：商品身份、标签、官方来源、监管/标准、口碑或价格中已经核到的事实。
- **缺口和下一步**：还缺配料表、保证分析、批号、标准号、旗舰店链接、评价截图等哪一项；用户要怎么补图或怎么买得更稳。

## 禁止与边界

- 不把未看到的配料表、保证分析或标签内容当成事实。
- 不把商品名、电商标题、条码命中、GS1/GDS/GDSN/Verified by GS1、GLN/厂商前缀或平台商品号当成配料表。
- 不把单包码、外箱码、销售组合码、混合装码互相替代；混合装没有逐口味标签时，不能说整套配料已核。
- 不因为价格低、销量高、旗舰店、达人推荐、小红书风评就下“安全健康”的结论。
- 不给慢病处方粮、减肥热量、补充剂或益生菌剂量；需要兽医营养方案时明确转兽医。
- 不做诽谤式判断。没有可靠证据时说“信息不足/未核到”，不要说品牌一定有问题。
- 不建议囤大量新产品给幼猫。先小量试吃，观察 24-48 小时大便、呕吐、精神和食欲。

## 常见结论模板

- “这款可以少量试，不建议现在囤：我能核到商品和价格，但没核到完整配料表/保证分析。给 mobi 这种幼猫，先按 5-10g 试吃，便便稳定再增加。”
- “这款不建议当主食：它更像零食/猫条，未看到全价和生命阶段信息。可以偶尔诱食，但不能替代完整均衡主食。”
- “这款暂不建议买：价格很低但公开信息不足，SKU 没完全匹配，幼猫不拿来赌。除非补包装背面和旗舰店链接再审。”
- “这款可作为轮换主食候选：已核到全价、适合生命阶段、标签关键项和渠道；仍需按换粮/试吃观察，不因爱吃就一次喂太多或长期单一口味。”
