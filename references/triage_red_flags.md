# 猫咪急症红旗分诊

目标：先识别不能等待的情况。命中红旗时，回答应先建议急诊或当日就诊，再补充解释。

## 急诊：立即联系急诊兽医

| 场景 | 红旗表现 | 回答重点 |
|---|---|---|
| 呼吸/循环 | 张口呼吸、呼吸明显费力、静息呼吸持续明显增快（约 >35-40 次/分钟）、腹部用力呼吸、伸脖子呼吸、不能趴下/不能睡、舌头或牙龈发紫/灰/苍白、虚脱、休克样无力；即使仍能吃、能叫、没张嘴，也不降级 | 立即急诊；保持安静、减少搬动和刺激；不要强迫蒸汽、吸入药或洗澡降温 |
| 排尿 | 反复进猫砂盆、蹲很久但只有几滴或无尿、像便秘一样用力、痛叫、舔尿道口、腹部痛，尤其公猫；母猫尿频、尿血、排尿痛也不能当安全 | 可能尿道阻塞或严重泌尿问题；无尿/几滴/痛叫/精神差按急诊，不要等到明天；不要挤压腹部或膀胱 |
| 中毒/危险暴露 | 已知或疑似接触百合、人用药、对乙酰氨基酚、菊酯/狗用驱虫药、老鼠药、防冻液、清洁剂、84/洁厕灵、消毒片、蚊香/电蚊液、樟脑丸、蟑螂药、除草剂、香薰/精油、人的皮肤药膏、未知毒物，即使目前吃喝正常 | 立即联系急诊兽医或毒物热线；带包装/照片；不要自行催吐、灌水、喂奶、喂油、喂活性炭或偏方 |
| 神经 | 抽搐、昏迷、突然瘫痪、无法站立、头歪伴严重失衡；抽搐超过 5 分钟、24 小时内反复、发作后不清醒或呼吸异常更紧急 | 立即急诊；记录发作时长和视频；不要把手指、毛巾或物品塞进嘴里，不要强按 |
| 外伤 | 车祸、高处坠落、被咬、开放伤、大出血、疑似骨折、眼球突出、眼睛被抓后眯眼/流泪/混浊/疼痛 | 立即急诊或当日就诊；高处坠落即使能走也要排查内伤；被咬小洞也可能深部污染；避免自行处理深伤口、滴人眼药或摆正骨折肢体 |
| 消化/异物 | 反复呕吐、喝水也吐、吐血/便血、腹部明显胀痛、疑似吞线绳/针/异物、幼猫严重腹泻 | 急诊或当日就诊；不要拉扯露出的线绳；幼猫更紧急 |
| 产科/生殖 | 未绝育母猫精神差、发热、阴道脓性分泌物、腹部胀大；第一产程超过约 24 小时无进展、用力 1-2 小时无幼猫、两只幼猫间隔超过约 2 小时且仍宫缩、幼猫卡住、产前黑绿/恶臭分泌物、大出血、产后虚弱/拒绝哺乳 | 立即就医；警惕子宫蓄脓或产科急症；不要在家用催产素/钙剂或硬拉幼猫 |
| 幼猫 | 不吃奶、体温低、体重不增/下降、持续哭叫、虚弱、脱水、腹泻、呕吐、呼吸异常 | 立即就医；幼猫恶化很快；保暖但不要强行灌喂冷、弱或吞咽差的幼猫 |
| 老年急变 | 老年猫突然失明、抽搐/昏厥、后肢瘫软或冰冷疼痛、严重嗜睡或喘、牙龈苍白、明显脱水、突然无法站立；糖尿病猫不吃/呕吐/虚弱/发抖/站不稳；老猫突然 24 小时不吃或母鸡蹲疼痛 | 急诊；老年猫急性变化可能涉及高血压、心脏病、肾病、糖尿病酮症酸中毒、低血糖或血栓等风险 |

## 当日就诊：不要长期观察

- 成年猫超过约 24 小时完全不吃，或伴随精神沉郁、黄疸、呕吐、脱水。
- 老年猫逐渐明显消瘦、多饮多尿、食欲大变、吃很多却变瘦、夜叫、毛乱、口臭、只舔汤不吃、行动痛苦；不要直接解释为“老了”或“性格变了”。
- 眼睛疼痛、眯眼、角膜混浊、突然看不见。
- 咳嗽、打喷嚏伴发热、精神差、拒食或呼吸声音异常。
- 乱尿、尿频、尿血、排尿痛，即使还有尿，也建议尽快检查。
- 伤口红肿热痛、流脓、发热或被其他动物咬伤。

## 可短期观察的前提

只有在猫精神好、能吃喝、正常排尿排便、症状轻微且短暂、没有毒物暴露和外伤时，才可给出短期观察建议。观察建议必须包含升级阈值。

用户说“可能没事、就一点、还能走、看着还好、先观察、明天再去、预算不够、附近没医院”时，不得降低红旗等级。先按症状本身分诊，再提供现实下一步：电话联系最近动物医院、询问急诊/分期/基础检查优先级、带证据材料。

如果用户所在地无法使用 ASPCA 或 Pet Poison Helpline，建议立即联系最近的急诊动物医院或有急诊能力的宠物医院；带上药品、植物、清洁剂、驱虫药包装或照片。

## 夜间/无急诊可达时

这不是观察建议，而是去不到急诊时的风险降低步骤：

1. 立刻电话询问最近动物医院是否有值班、能否转诊、能否先做稳定处理。
2. 搜索关键词：`24小时 宠物急诊`、`动物医院 急诊`、`夜间急诊`。
3. 联系朋友、网约车、救助群或附近猫友协助转运。
4. 路上保持安静、保暖、少刺激；带包装/照片/视频/时间线。
5. 预算有限时，电话先问诊费、夜诊费、基础检查价格、分期或救助渠道；优先做能改变生死决策的检查和稳定处理，不用自行买药替代就医。

## 高风险家庭操作：明确不要做

| 场景 | 不要做 |
|---|---|
| 疑似尿闭 | 不要挤压腹部或膀胱，不要喂偏方利尿 |
| 抽搐 | 不要把手指或物品塞进嘴里，不要强行按住 |
| 呼吸困难 | 不要强迫抱持、洗澡、蒸汽、运动或使用非处方吸入药 |
| 线绳异物 | 不要拉扯口腔或肛门露出的线 |
| 创伤/骨折 | 不要摆正骨折肢体，不要深部清创 |
| 中暑/高热 | 不要冰水浸泡；可在联系急诊途中按兽医建议温和降温 |

## 急症回答模板

> 这属于急诊风险，建议现在联系急诊兽医/最近动物医院。不要自行给药或等待网上排查。路上尽量让它安静保暖，带上症状视频、时间线、最近排尿排便记录，以及可能接触到的药物/植物/包装。
