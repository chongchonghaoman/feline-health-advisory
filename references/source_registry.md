# 来源登记表

用途：回答时选择权威来源，并知道哪些主题需要最新核验。不要编造不存在的指南条文。

`references/sources.yaml` 是结构化来源登记和唯一真源；本文件只是人类可读摘要。回答中命名某个指南前，应先确认这里或 `sources.yaml` 里有对应来源。

## 需要联网核验的主题

- 最新疫苗指南、接种间隔、地区性强制要求。
- 某地区流行传染病、寄生虫风险。
- 药品召回、毒物清单、食品召回。
- 新兴疾病或治疗方案，例如 FIP 治疗可及性和当地法规。
- shelter medicine 页面、消毒建议或隔离建议的当前版本。

## 无法联网时的 fallback

| 场景 | 做法 |
|---|---|
| 疑似急症或中毒 | 不继续查来源耽误行动；建议联系急诊兽医、毒物热线或最近有急诊能力医院 |
| 召回/食品/药品安全 | 建议用户查 FDA/AVMA、品牌官网或当地监管页面；保留包装和批号；有症状则就医 |
| 疫苗/驱虫/地区风险 | 只讲原则，不给当前本地程序或地区结论 |
| FIP 治疗可及性/法规 | 说明需本地兽医核验；不提供购买、用药或规避法规建议 |

## 剂量泄漏风险

专业来源可能含药物、麻醉、毒物处置、胰岛素、NSAID、抗生素、驱虫、消毒或手术流程。面向猫主回答时只输出风险框架、就医必要性、兽医可能检查方向和安全准备；不得摘录剂量、频率、疗程、mg/kg、操作步骤或处方调整。
