# 来源登记表

用途：回答时选择权威来源，并知道哪些主题需要最新核验。不要编造不存在的指南条文。

`references/sources.yaml` 是可维护的结构化来源登记；本文件是人类可读摘要。回答中命名某个指南前，应先确认这里或 `sources.yaml` 里有对应来源。

## 需要联网核验的主题

- 最新疫苗指南、接种间隔、地区性强制要求。
- 某地区流行传染病、寄生虫风险。
- 药品召回、毒物清单、食品召回。
- 新兴疾病或治疗方案，例如 FIP 治疗可及性和当地法规。

如果无法核验官方来源：说明“我无法确认最新/本地规则”，避免给出当前年份、当地强制要求或具体医疗程序。
